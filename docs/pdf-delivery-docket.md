# Delivery Docket PDF

Layout and field map for Field’s **delivery docket**, captured from a licensed-product sample.

**Source sample:** [`samples/delivery-docket-source.pdf`](samples/delivery-docket-source.pdf)  
**Task in sample:** ID `28D5AAE802`, status `Completed`, External ID `99290`  
**Generator (local):** `npm run pdf:docket` → `storage/documents/`

See also: [`critical-features.md`](critical-features.md), [`task-model.md`](task-model.md).

---

## Purpose

Job packet for the crew / warehouse: where to go, who receives, task summary, description, and a POD block (filled when completed; blank/`n/a` otherwise).

In the source system this is one living document — the same docket template includes POD when the task is completed. Field should match that: one `delivery_docket` kind; POD section reflects completion data when present.

---

## Page layout (top → bottom)

Single page, portrait, white background. Label/value rows (label left, value right of a modest gap). Section titles are bold. Missing values render as `n/a`.

```text
┌─────────────────────────────────────────────────────────────┐
│ Task ID: {id}              Completed on {completed_at}      │  ← completed line only if completed
│ Delivery Docket                                             │
│ Company          {company_name}                             │
│                                                             │
│ Destination Location                                        │
│ Contact        …                                          │
│ Address          …                                          │
│ Building         …                                          │
│ Email            …                                          │
│ Phone            …                                          │
│ Instructions     …                                          │
│                                                             │
│ Summary                                                     │
│ External ID      …                                          │
│ Type             …                                          │
│ Priority         …                                          │
│ Crew             …                                          │
│ Status           …                                          │
│ Created          …                                          │
│                                                             │
│ Description                                                 │
│ {task description, multiline}                               │
│                                                             │
│ POD                                                         │
│ Received by      {name}, {completed_at}                     │
│ Notes            …                                          │
│                                                             │
│ Name ________  Signature ________  Date ________            │
│                                                             │
│ Generated by {company} on {yyyy-mm-dd hh:mm}        1 / 1   │
└─────────────────────────────────────────────────────────────┘
```

### Header

| Element | Notes |
|---------|--------|
| Task ID | Short/hex style in sample (`28D5AAE802`); Field may use numeric `Id` until format is decided |
| Completed on | Right-aligned; omit or leave blank when status ≠ Completed |
| Title | Literal `Delivery Docket` |
| Company | Org display name (config, not a task field) — sample: `Quick Change Display` |

### Destination Location

| Label | Source field (task model) |
|-------|---------------------------|
| Contact | `RecipientName` |
| Address | `DestinationAddress` |
| Building | `DestinationBuilding` |
| Email | `RecipientEmail` (may be comma-separated; print as stored) |
| Phone | `RecipientPhone` |
| Instructions | `DestinationNotes` |

### Summary

| Label | Source field |
|-------|--------------|
| External ID | `ExternalKey` |
| Type | `TaskType` |
| Priority | Not in draft task model yet — sample used `Normal`; default `Normal` until modeled |
| Crew | Assigned crew member display name (`DriverName` in reference export) |
| Status | `Status` |
| Created | `CreatedDateTime` (display: `MMM D YYYY h:mm A`) |

### Description

| Label | Source field |
|-------|--------------|
| (body) | `TaskDesc` |

### POD

| Label | Source field |
|-------|--------------|
| Received by | Receiver name + `CompletedDateTime` (sample: `Genevieve , Jul 15 2026 01:09 PM`) — receiver name not yet on task model |
| Notes | `CompletedNotes` |
| Name / Signature / Date | Blank underline lines for wet-ink or print signing |

### Footer

| Element | Notes |
|---------|--------|
| Generated by | `{company_name} on {yyyy-mm-dd HH:mm}` (generation time, not task created) |
| Page | `{current} / {total}` |

---

## Display conventions (from sample)

- Empty / null → `n/a`
- Datetimes in body: `MMM D YYYY h:mm A` (e.g. `Jul 15 2026 01:09 PM`)
- Footer timestamp: `yyyy-mm-dd HH:mm` (24h)
- Company name appears in header row and footer
